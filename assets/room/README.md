# `assets/room` — la piso acogedor de Barcelona

Единственный файл ассетов сцены: **`bg_room.png`** — уютная вечерняя квартира в Барселоне
(диван, столик с бокалами, балкон/окно с силуэтом города, проигрыватель с колонкой, растения,
тёплый свет). Pixel art, выведен через `image_generate` и постобработан PIL:
центр-кроп под аспект телефона + LANCZOS-ресайз в **708x1536** (пиксель-в-пиксель портрет 430x932).

Никаких надписей на фоне нет (по ТЗ), персонажи не нарисованы — их накладывает интегратор.

## Почему 708x1536

`RoomScene` рисует фон как `BoxFit.cover`: масштаб `max(canvasW/708, canvasH/1536)`, центр.
Аспект арта (0.4609) отличается от экранов приёмки на десятые доли процента, поэтому
растяжения нет и обрезается всего ~2 px по высоте:

| Экран      | cover-масштаб | обрезка  | floor line Y |
|------------|---------------|----------|--------------|
| 390 x 844  | 0.5508        | 0 x 2.1  | 671.6        |
| 430 x 932  | 0.6073        | 0 x 0.9  | 741.2        |

Масштаб не целочисленный, но отрисовка идёт с `FilterQuality.none` (`isAntiAlias: false`
в виджете) — пиксели остаются чёткими, без мыла.

## Интерактивные зоны

Координаты хранятся **нормализованными относительно арта** (`RoomZones` в
`lib/features/room/room_layout.dart`) и пересчитываются в пиксели экрана через `RoomLayout`,
так что одинаковы на любом телефоне. `left/top` — от левого верхнего угла арта.

| id       | что это                    | нормализовано (l, t, w, h)          | 390x844 (px)              | 430x932 (px)              |
|----------|----------------------------|-------------------------------------|---------------------------|---------------------------|
| `sofa`   | диван с пледами            | 0.300, 0.530, 0.440, 0.270          | 117, 447, 172x228         | 129, 494, 189x252         |
| `table`  | столик с бокалами          | 0.360, 0.720, 0.290, 0.150          | 140, 608, 113x127         | 155, 671, 125x140         |
| `window` | окно / балкон (Barcelona)  | 0.055, 0.140, 0.305, 0.380          | 21, 117, 119x322          | 24, 130, 131x355          |
| `music`  | проигрыватель + колонка    | 0.655, 0.470, 0.290, 0.300          | 256, 397, 113x254         | 282, 438, 125x280         |
| `plants` | растения (декор)           | 0.020, 0.550, 0.170, 0.330          | 8, 464, 66x279            | 9, 513, 73x308            |

- **HUD safe area** — верхняя полоса `RoomLayout.hudSafeArea`: `min(108, 0.2 * height)` px
  (108 px = заголовок + счётчик рыб). Ни одна зона и ни один персонаж не заходят выше неё.
- **floor line** — `RoomLayout.floorLineY` = 79.5% высоты арта: на этой линии стоят все
  персонажи (`standPoint(id, height:)` возвращает центр объекта на полу по центру зоны).

## Как подключить

Flame (основной путь, уже включён в игру через `lib/features/features.dart`):

```dart
final room = RoomScene();       // priority -100 => фон позади персонажей
await add(room);
await add(cats);                // персонажи сверху
final feet = room.standPoint('sofa', height: 72);
final zone = room.zoneAt(tapPosition); // 'music', 'window', ...
```

Flutter-виджеты: `RoomBackdrop(child: ..., builder: (layout) => ...)` — та же cover-математика
и те же зоны через `RoomLayout`.

Отладка: `RoomScene(showZoneDebug: true)` (или `RoomBackdrop(showZoneDebug: true)`) рисует
прямоугольники зон, HUD-полосу и линию пола.

Визуальная проверка обеих приёмок в браузере (реплика cover-математики на JS):

```bash
python3 -m http.server 8321      # из корня репо
# http://localhost:8321/tool/room_preview.html
```
